# Creative Developer Portfolio

---

## Description

Currently working on updating my portfolio site to an updated design that utilizes Three.js for a more interactive and unique user experience. The new design features a fully interactable 3D Sony PlayStation Portable (PSP) console that offers a more engaging way to explore my projects and personality.  

This portfolio aims to showcase not just my work, but also my approach to creative and interactive web development. By integrating 3D elements and immersive UI interactions, visitors can explore content in a way that blends visual storytelling with hands-on exploration.

---

## Features

- **Interactive Sony PlayStation Portable:** Explore a detailed, fully rotatable and clickable 3D PSP model that acts as a central hub for navigating my portfolio projects.
- **Custom 3D Depth Map:** Achieved a realistic 3D effect on PNG images using a unique `.stl` lithophane approach, creating depth and texture for visual content.
- **Dynamic Project Previews:** Projects are showcased in a visually appealing and interactive manner, allowing users to preview work directly from the 3D console interface.
- **Responsive 3D Interaction:** Designed for smooth interaction on both desktop and mobile devices, leveraging Three.js optimizations and React Fiber for performance.
- **Immersive Animations:** Subtle hover and click animations on the PSP elements enhance engagement and provide an intuitive navigation experience.

---

## Technologies Used

- **Frontend**: [Next.js](https://nextjs.org/), TypeScript, TailwindCSS  
- **3D / Graphics**: Three.js, React Three Fiber
- **Assets & Modeling**: Blender (for 3D PSP model), Custom PNG depth maps

---

## Installation

To run the project locally, follow these steps:

1. Clone the repository:
```
git clone https://github.com/ericrisher/caligo.git

cd caligo
```
2. Install dependencies:
```
npm install
```
3. Run the development server:
```
npm run dev
```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
